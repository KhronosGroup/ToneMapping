# トーンマッパー

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh-CN.md">简体中文</a> · <a href="./README.ja.md">日本語</a></p>

3D グラフィックスを表示するためのトーンマッパーのコレクションです。具体的には、最高性能の HDR テレビよりも数桁広いレンジを持つ PBR 由来の HDR リニアライトを、SDR やその他の表示デバイスの出力レンジに変換します。

## [PBR Neutral](PBR_Neutral)
PBR の色精度に特化して設計されたトーンマッパーで、グレースケール照明下において、出力レンダリングの sRGB 色を入力の sRGB baseColor に可能な限り忠実に一致させます。これは、シーンが適切に露出され、HDR の色値が主に小さな鏡面ハイライトに限定される製品写真のユースケースを対象としています。
